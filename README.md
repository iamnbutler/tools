# tools

Tools we've built. One line each; newest thinking wins, so edit freely.

## Agents

- **[autoblog](https://github.com/iamnbutler/autoblog)**: coding agents write up what we do as a private journal.
- **[telephone](https://github.com/iamnbutler/telephone)**: Rust CLI and MCP server for messaging between Claude Code and Codex sessions on one Mac.
- **[porthole](https://github.com/iamnbutler/porthole)**: let agents work on another Mac's screen, apps and audio over Tailscale.
- **[desktop-tools](https://github.com/githubnext/desktop-tools)**: let agents see and operate native macOS apps, through an MCP server and a signed app that holds the permissions.
- **[spool](https://github.com/iamnbutler/spool)**: git-based task board for humans and agents, with a CLI and a ratatui TUI.
- **[tasks](https://github.com/iamnbutler/tasks)**: agent orchestrator that runs coding agents in Linux VMs.
- [margin](https://github.com/iamnbutler/margin): review agents' pages and message their Claude Code sessions from your phone.
- [prompts](https://github.com/iamnbutler/prompts): reusable prompts and agent skills: diagram and illustration styles, site themes, explainer pages, research and testing.
- [thread-history](https://github.com/iamnbutler/thread-history): backs up Claude Code and Codex session history from every machine into one place.

## Dictation and voice

- **[ramble](https://github.com/iamnbutler/ramble)**: LLM-polished push-to-talk dictation for macOS.
- [yap](https://github.com/iamnbutler/yap): menu bar dictation built for talking to Claude Code: hold a key, talk, and the text lands in the app in front.

## Libraries

- **[gpuikit](https://github.com/iamnbutler/gpuikit)**: UI component kit for GPUI: buttons, inputs, menus, markdown, an editor and themes.
- **[gpui-tools](https://github.com/iamnbutler/gpui-tools)**: GPUI docs and examples written for humans and agents.
- **[gpui-editor](https://github.com/iamnbutler/gpui-editor)**: a standalone editor component for GPUI.
- **[ferrotype](https://github.com/iamnbutler/ferrotype)**: Rust-to-TypeScript type generation.
- **[crdt](https://github.com/iamnbutler/crdt)**: plain-text CRDT in pure TypeScript, benchmarked against Yjs, Loro and Automerge.
- **[multibuffer](https://github.com/iamnbutler/multibuffer)**: Zed-style multibuffer editor component for the web.
- **[derive_static_str](https://github.com/iamnbutler/derive_static_str)**: proc macro for composing static string slices from enum variants.

## Apps

- **[open-tv-remote](https://github.com/iamnbutler/open-tv-remote)**: free TV remote for iPhone, iPad and Mac: Google TV, Roku, Samsung and LG.
- **[parade](https://github.com/iamnbutler/parade)**: downloads AO3 fics as EPUBs into an iCloud library and sends them to Apple Books.
- **[maple](https://github.com/iamnbutler/maple)** and **[msapi](https://github.com/iamnbutler/msapi)**: MapleStory gear tracker driven by an agent, and the typed API under it.
- **[Shelf Goblin](https://shelfgobl.in)**: LitRPG audiobook catalog: follow series and track your library.
- **[Chart Atlas](https://chart-atlas.iamnbutler.pages.nexthub.sh)**: 152 chart types in a searchable grid, for picking a chart form.
- [klaxon](https://github.com/iamnbutler/klaxon): menu bar reminders that escalate from a banner to a full-screen takeover, and reach your phone through iMessage and Pushover.
